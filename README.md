# wira-systems/.github

The Wira Systems organisation's own files on GitHub:

- [`profile/README.md`](profile/README.md) is the organisation's front page.
- [`CONTRIBUTING.md`](CONTRIBUTING.md), [`SECURITY.md`](SECURITY.md) and [`SUPPORT.md`](SUPPORT.md), the pull request template and the issue forms in [`.github`](.github) are the defaults for every Wira Systems repository without its own.

A repository's own file of the same name takes its place there.
